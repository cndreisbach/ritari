Built the Pi integration as an npm package. Decided pi-ritari lives in this repo (versioned with the CLI), the package owns the brief, and typed tools are worth building without a routing measurement. Added rit --output json as newline-delimited flat objects (spec §9.1), then pi-ritari/: four TypeBox tools (search, read, write, edit) over the CLI, project resolution that names the project and refuses an unregistered ritari.yaml, write guards (existing title needs its id; body replacement needs the hash), the session-start brief, vitest coverage, and CI/release wiring that publishes pi-ritari on a tag when it changed. Removed the generated Pi hook from rit install hooks (breaking), deleted this repo's copy, and git-ignored .pi/.

Added a version-mismatch message to the client. Testing locally now needs this repo's bin/ first on PATH.
